Only add the custom icons you want. An absent or unreadable custom icon

The favicon stays on the bundled original icon.

3. FILE FORMAT
Use real PNG images with the exact lowercase filenames above.
Export/convert JPG or WebP to PNG; do not just change the extension.
NFTs: square recommended, around 1000x1000.
Icons: square transparent PNG recommended, 128x128 or larger.
Images are fitted without cropping.

4. INSTALLATION
Extract this entire ZIP and use its index.html, css, js and assets folders.
The new js/asset-loader.js file is required for image fallback behavior.
After adding images, refresh the page. If old images are cached, hard refresh
(Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows).

Whitelist backend setup is unchanged; see README.md.
